# Tapiopon-Addon
不思議な生き物、たぴおぽんが追加されます

## 導入方法
たぴおぽんアドオンのビヘイビアパックとリソースパックを追加してください。

## 配信や動画に使用する場合について
以下の注意事項を守ってご自由にご利用ください。
  - 自作発言はやめてください。
  - たぴおぽんの音声は想像とは全く違うと思うので配信をする際は一度たぴおぽんアドオンをテストすることをオススメします。
